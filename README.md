## Project Overview

Crave Bite is a UI/UX design project for a food delivery mobile application. The app provides a seamless experience for users to browse restaurants, explore menus, place orders, and track deliveries in real time.

The design follows a user-centered approach with a clean layout, consistent styling, and intuitive navigation.


## Features

* Browse restaurants and food categories
* View detailed menu items
* Add items to cart
* Apply offers and discounts
* Real-time order tracking
* Delivery partner information



## User Flow

Browse Food → Select Items → Add to Cart → Apply Offers → Place Order → Track Delivery
